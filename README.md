# Harmonic-Mean Consensus Secondary Control of Grid-Forming Inverters — Simulation Code

Complete simulation code for the manuscript:

> M. A. Tufail, M. A. Abido, and A. Mustafa, "Harmonic-Mean Consensus Secondary
> Control of Grid-Forming Inverters: Provably Overload-Free Power Sharing and a
> Frequency-Recoverability Limit," submitted to *Computers and Electrical
> Engineering* (manuscript COMPELECENG-D-26-07208).

Every figure, table, and reported number in the paper is generated by the
scripts in this repository.

## Contents

| File | What it reproduces |
|---|---|
| `paper1_reproduce.m` | Main script (Sections A–K): Scenarios 1–8 and Tables 2–3 (A, I); no-overload/minimax study, Fig. 4 (B); power-mean ordering on the test graph (C); predictor–corrector round-halving (D); inertia/connectivity sensitivity, Fig. 11 (G); frequency-recoverability limit, Fig. 12 (F); IEEE 14-bus study, Fig. 13 (H); sensitivity suite — packet loss, ±20 % parameter Monte-Carlo, measurement bias, communication partition, transient saturation — Section 10.15 and Fig. 15 (J); 500-graph random ensemble statistics for Table 3 and Remarks 3–5, plus the fastest-mixing-chain and equal-budget SDP benchmarks of Section 10.10 and Fig. 10 (K). Section K also verifies the Theorem-4 damping bound numerically over 2×10⁵ random samples. |
| `constudy.m` | Method-level comparison of Section 10.3, Fig. 3: proposed law vs. frequency-DAPI, event-triggered per-unit consensus, and PI-consensus, implemented per Appendix A. |
| `head_to_head.m` | Head-to-head closed-loop comparison of Section 10.9, Fig. 9 (proposed vs. Metropolis-weighted comparators; Perron spectral radii; Fig. 8 decay comparison). |
| `verify_thm1_normalized.py` | Exact source of Remark 4's equal-budget statistics (harmonic family-best in 384/500 graphs, mean ratio 0.9906, minimum 0.7960) at numpy seed 7, under the ensemble law stated in Section 10.7. |
| `ga2_build.py` | Self-contained generator of the graphical abstract (regenerates its frequency traces with the same plant, RK4 @ 1 ms, Ts = 20 ms, and conditional anti-windup as the MATLAB engine). |

## Requirements

- **MATLAB** R2019b or later (base MATLAB only for Sections A–J and K1).
- **CVX** (http://cvxr.com) — required only for the SDP benchmarks of Section K2;
  without it, K2 is skipped with a notice and everything else runs.
- **Python 3.9+** with `numpy`, `networkx` (for `verify_thm1_normalized.py`),
  and `matplotlib` (for `ga2_build.py`).

## How to run

```
>> paper1_reproduce      % runs Sections A–K, prints all metrics, saves all figures
>> constudy              % Fig. 3 comparison
>> head_to_head          % Figs. 8–9 comparison

$ python verify_thm1_normalized.py    % Remark 4 exact statistics (seed 7)
$ python ga2_build.py                 % graphical abstract (PNG/TIFF/PDF)
```

Full run time is a few minutes; Section K2's 240 CVX solves dominate.
All random studies use fixed seeds, so the printed numbers reproduce exactly
run-to-run; they match the values reported in the manuscript.

## Key reproduced values (for quick verification)

- Scenario 1: nadir 49.965 Hz, sharing settles in 9 updates (0.18 s), final error ≈ 4×10⁻¹⁵.
- Minimax study: per-unit consensus r = 0.8516 on every unit; MW-averaging pins two units at 1.022.
- Recoverability: measured infeasible RoCoF −0.2335 Hz/s vs. closed-form −0.2328 Hz/s.
- Ensemble (Section K, fixed seed): harmonic largest λ₂ in 500/500 graphs; ratio-of-means 1.63× vs. Metropolis.
- Benchmarks (Section K2): 82 % of the fastest-mixing (free-weight) gap on average, 89 % vs. the nonnegative variant (optimum attained exactly on 15/80 graphs), 66 % under the equal-budget λ₂ program.
- Theorem-4 damping-bound check: max(lhs − rhs) ≤ 0 over 2×10⁵ samples.
